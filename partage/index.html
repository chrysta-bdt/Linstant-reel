⬇️ Télécharger la vidéo
  1. Appuie sur Télécharger la vidéo, puis sur Télécharger dans la fenêtre qui s'ouvre.
  2. Attends la fin du téléchargement (la petite flèche bleue en haut de Safari).
  3. Ouvre l'appli Fichiers → Téléchargements → appuie sur la vidéo.
  4. Bouton Partager → Enregistrer la vidéo : elle arrive dans tes Photos.

Ouvre cette page dans Safari (pas dans une autre appli). La vidéo fait 50 Mo : mieux vaut être en Wi-Fi.
